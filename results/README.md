# Generated results

This folder contains manuscript figures and derived tables generated by the
top-level MATLAB workflows. Running `reproduce_all` with its default options
regenerates the current outputs and overwrites files with matching names.

## Output map

### `exploratory_figures/`

Generated by the analytical `explore*.m` scripts:

- call-rate–distance and call-duration–distance figures;
- IPI, call-rate spread, and duration summaries across information
  conditions;
- acoustic-acquisition and behavioural-interval summaries;
- buzz-readiness figures and sequence-level metrics;
- terminal-window figure and associated comparisons.

PDF files are intended for manuscript inclusion; PNG files provide
high-resolution previews. CSV files hold the numerical summaries underlying
the plots and statistical comparisons.

### `field_data_exploration/`

Generated by `exploreFieldData.m`:

- `field_vs_sim_observables.*`;
- `field_vs_sim_timing_diagnostics.*`;
- effective-velocity and velocity-band summaries;
- timing interaction and residual summaries;
- seeded duration-envelope compatibility summaries;
- conditional distance, behavioural-interval, and acquisition-window
  profile summaries;
- the screened downstream table
  `vof_processed_data_cleaned.csv`.

The legacy timing-decomposition figure and several extended sensitivity
figures remain available through switches near the top of
`exploreFieldData.m`, but are disabled by default. Figure generation and
table generation can be controlled independently through `reproduce_all`.

The `simulation_cache/` subfolder is created when simulation-table saving is
enabled. Compatible caches are loaded automatically to avoid rerunning the
larger stochastic ensembles; changing an associated analysis parameter
invalidates and regenerates the relevant cache.

### `ssg_analysis_figures/`

The current `runCoreSSGAnalysisPipeline.m` writes
`ssg_analysis_composite.pdf` and `.png`. Additional panel-level SSG files in
this directory are earlier exports retained for inspection; the composite
figure is the current pipeline output.

### Root-level SSG tables

Generated by `runCoreSSGAnalysisPipeline.m`:

- `core_simulated_temporal_patterns_ssg.csv` — call-level simulation and
  SSG labels. This reproducible file is generated locally but excluded from
  Git because its full output exceeds GitHub's standard per-file size limit;
- `core_ssg_event_summary.csv` — detected SSG events;
- `core_ssg_event_analysis_summary.csv` — compact event-level analysis;
- `core_ssg_event_summary_by_condition.csv` — condition-level summary.

### `validation_figures/`

Created when validation figure saving is enabled. It contains one
`core_equation_validation_<scenario>` PDF/PNG pair for each validation
scenario.

## Reproduction without writing

To execute the analyses without replacing these files:

```matlab
reproduce_all(SaveFigures=false, SaveTables=false)
```

All generated figures remain open for inspection by default. For a
lower-memory batch run that retains only the latest component’s figures:

```matlab
reproduce_all(KeepFigures=false)
```
